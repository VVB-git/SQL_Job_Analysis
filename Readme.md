## Анализ
Каждый запрос в этом проекте был нацелен на изучение конкретного аспекта рынка вакансий Data Analyst. Вот как я подходил к каждому вопросу:
### 1 - Самые высокооплачиваемые работы для аналитиков данных
- Заджойнил job_postings_fact с company_dim
- Через where отфильтровал только те вакансии, где
  - формат работы - удаленный
  - поле с годовой зарплатой не пустое
  - оставил только вакансии для аналитиков данных
```sql
select 
    job_id,
    job_title,
    job_location,
    job_schedule_type,
    salary_year_avg,
    job_posted_date,
    company_dim.name
from job_postings_fact
left join company_dim on job_postings_fact.company_id = company_dim.company_id
where 
    job_location = 'Anywhere'
    AND
    salary_year_avg is not null
    AND
    job_title_short = 'Data Analyst'
order by salary_year_avg desc
limit 10;
```

### 3 - Самые востребованные скилы
- Тут я опять соединил таблицы. В этот раз 3-и, что бы в итоговой была инфа и по вакансиям и по скилам
- Сгруппировал по скиллам
- И оставляем 5 самых часто встречающихся 
```sql
select 
    skills,
    count(*) as skill_popularity
from
    job_postings_fact
inner join skills_job_dim on 
    job_postings_fact.job_id = skills_job_dim.job_id
inner join skills_dim ON
    skills_job_dim.skill_id = skills_dim.skill_id
where job_title_short = 'Data Analyst'
group by skills_dim.skills
order by skill_popularity desc
limit 5;
```

### 4 - Средняя зарплата по каждому навыку
- Соединение таблиц. Навыки и инфа по вакансиям - вместе
- Фильтруем по тем вакансиям, которые для аналитиков данных и зарплата указана
- Группируем по скилам
- Считаем по ним средние годовые зарплаты
```sql
select 
    skills,
    count(*) as skill_popularity,
    Round(avg(salary_year_avg),1) as avg_salary_per_skill
from job_postings_fact
join skills_job_dim ON
    job_postings_fact.job_id = skills_job_dim.job_id
join skills_dim ON
    skills_job_dim.skill_id = skills_dim.skill_id
where 
    job_title_short = 'Data Analyst'
    AND
    salary_year_avg is not null
group by skills
-- having count(*) > 30
order by avg_salary_per_skill desc
limit 25;
```

## Выводы

- Python и R выделяются — спрос 236 и 148 вакансий соответственно. Несмотря на высокий спрос, средние зарплаты держатся на уровне ~$101 397 для Python и ~$100 499 для R. Это значит, что навык ценят, но он широко распространён

- Облачные технологии: Snowflake, Azure, AWS и BigQuery показывают заметный спрос и относительно высокие зарплаты. 

- BI и визуализация: Tableau и Looker — спрос 230 и 49 вакансий, средние зарплаты ~$99 288 и ~$103 795. Подтверждает, что визуализация и бизнес-аналитика критичны для превращения данных в решения.

- Базы данных: спрос на традиционные и NoSQL базы (Oracle, SQL Server, NoSQL) со средними зарплатами от $97 786 до $104 534. Показывает, что навыки хранения, извлечения и управления данными остаются востребованными.
